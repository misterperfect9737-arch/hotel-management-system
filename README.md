# Grand Luxe Hotel Management System

Modern hotel management system with real-time booking and dynamic billing.

## Run Commands

```bash
cd "C:\Hotel System"
py test_server.py
```

Then open: **http://localhost:5000**

## Project Files

```
Hotel-Management-System/
├── index.html          Frontend interface (HTML)
├── styles.css          Styling (CSS)
├── script.js           Business logic (JavaScript)
├── app.py              Backend API (Python Flask)
├── test_server.py      Simple server (Python)
├── database.sql        Database schema (MySQL)
└── requirements.txt    Dependencies
```

## Features

- Real-time room booking
- Dynamic billing with GST (12%)
- Admin dashboard with analytics
- Room availability tracking
- Indian Rupee pricing (₹2,500 - ₹12,000)
- Modern dark theme with animations

## Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: Python Flask
- **Database**: MySQL (optional)

## Stop Server

Press `Ctrl + C` in terminal
